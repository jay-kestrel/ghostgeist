## 2. Description of Service

GhostGeist is an Engineering Shadow Work Reconciliation Platform for Atlassian Jira Cloud and GitHub. It provides:
- Automated discovery of untracked GitHub Pull Requests lacking Jira issue keys.
- AI-assisted analysis and issue synthesis via Google Gemini.
- 1-click reconciliation into Atlassian Document Format (ADF) Jira issues with bi-directional GitHub remote links.
- Atlassian Rovo Agent and Model Context Protocol (MCP) integrations.
